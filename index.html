Rak kaset

    Lagu sendiri

    Tarik file lagu (MP3, M4A, WAV, OGG) ke sini atau pilih dari perangkat. Game membaca ketukannya lalu menyusun jalur nada otomatis, jadi lagu Indonesia favoritmu bisa dimainkan dari file milikmu. File diproses di perangkatmu dan tidak diunggah.

    Lagu dari Spotify atau Apple Music?

    Game ini tidak bisa terhubung langsung ke Spotify atau Apple Music. Lagu streaming tidak tersedia sebagai file yang bisa dibaca, dan unduhan dari langganan Apple Music dilindungi DRM. Yang bisa dimainkan adalah file MP3, M4A, WAV, atau OGG yang kamu miliki, misalnya lagu yang dibeli di iTunes Store (bebas DRM sejak 2009), hasil rip CD sendiri, atau unduhan resmi dari artisnya.
